Pick a country and rate, enter an amount, and get the **net / VAT / gross** breakdown — either direction (add VAT to a net price, or back out VAT from a gross price).

## ✨ Features

- **All 27 EU countries + UK**, with standard and common reduced rates, plus a zero-rate option
- **Add VAT** (net → gross) or **Remove VAT** (gross → net)
- Clean net / VAT / gross result cards
- A full **rate reference table** for every country

## ⚠️ A note on accuracy

The rates included are **standard published VAT rates** for general reference. VAT has many
product-specific exceptions and rules change over time — for compliance-critical filings,
always confirm the applicable rate with the official tax authority. This tool does the
arithmetic reliably; it doesn't replace tax advice.

## 🧰 Tech

- **Vanilla HTML / CSS / JavaScript** — no frameworks, no dependencies, one `index.html`
- Add/remove math is exact and round-trips (remove then add returns the original)
- Hosted free on **GitHub Pages**; nothing is uploaded

## ▶️ Run locally

```bash
start index.html      # Windows — no build step
```
